# CoolCam

CoolCam is a school project concept for a fridge camera and companion app. The app source is in [`coolcam-demo/`](coolcam-demo/).

## Run it in VS Code

Open this folder in VS Code, then use **Terminal → New Terminal**:

```sh
npm install
npm run dev
```

Open the `http://localhost:...` address printed by Vite. Keep the terminal running while you use the app.

See [`coolcam-demo/README.md`](coolcam-demo/README.md) for concept details and GitHub Pages publishing instructions.
